## 🛠️ The Dual-Project Methodology

Every model family implemented in this portfolio follows a rigorous double-faceted standard:

1.  **Project 1: Scratch Mathematical Derivation & Implementation**
    *   **LaTeX Proofs**: Analytical derivations of losses, cost gradients, and optimization rules.
    *   **Vanilla NumPy Estimators**: Clean, object-oriented estimators written completely from scratch (implementing `.fit()`, `.predict()`, `.evaluate()`), showcasing an absolute command of algorithmic mechanics without third-party black boxes.
2.  **Project 2: Advanced Industrial Application**
    *   **Production Pipelines**: Real-world data engineering pipelines employing state-of-the-art libraries (`Scikit-Learn`, `PyTorch`, `LightGBM`, `Optuna`, `Prophet`).
    *   **Modern Challenges Solved**: Handling highly imbalanced data (SMOTE), box-cox and power transforms, advanced hyperparameter tuning (Bayesian Search), model interpretability (SHAP/Feature Importances), and deployment considerations.

## 🚀 How to Run Locally

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/ml-galaxy-portfolio.git
cd ml-galaxy-portfolio
```

### 2. Set Up Python Environment & Run Jupyter
Ensure Python is installed, then:
```bash
python -m venv venv
# On Windows
.\venv\Scripts\activate
# On macOS/Linux
source venv/bin/activate

pip install -r requirements.txt # (Contains NumPy, Pandas, Scikit-Learn, PyTorch, LightGBM, Optuna, Prophet, Jupyter)
jupyter lab
```

### 3. Open the Companion Dashboard
Simply open `index.html` in your default web browser, or run a local lightweight server:
```bash
# Using python:
python -m http.server 8000
# Then visit http://localhost:8000 in your browser!
```
